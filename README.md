# CityMETER: Yolk · โหมดสำนักงานพลังงานจังหวัด (ชัยนาท)

เดโมการใช้ CityMETER: Yolk กับภารกิจของสำนักงานพลังงานจังหวัดชัยนาท เครื่องคิดเดียวกับโหมดขยายสาขาของธุรกิจ คือ ความต้องการ → กิจการที่มีอยู่ → โอกาส → คิวลงพื้นที่ ต่างกันที่ตัววัด เกณฑ์ และมุมมองโอกาส ซึ่งโหมดนี้ผูกกับแผนปฏิบัติราชการด้านพลังงาน จ.ชัยนาท 2566–2570 และอำนาจหน้าที่ของสำนักงาน

**เปิดเดโม:** https://montri-th.github.io/chainat-energy/

เป็นต้นแบบสาธิต ไม่ใช่ระบบราชการที่เปิดใช้งานจริง ตัวเลขความต้องการรายพื้นที่และรายอาคารเป็นแบบจำลองจากยอดจังหวัดจริง

## ใช้ทำอะไร

| เมนู | สิ่งที่ทำได้ |
| --- | --- |
| ภาพรวม | ข้อมูลที่มีวันนี้พร้อมที่มา เกณฑ์ที่ผูกกับแผน 3 แผนงาน และอำนาจหน้าที่ 8 ข้อ |
| ความต้องการ | แผนที่การใช้ไฟฟ้า น้ำมัน LPG และรถจดทะเบียนรายตำบลหรือราย อปท. (แบบจำลองจากยอดจังหวัด) ตั้งเกณฑ์ไข่แดงได้ไม่เกิน 3 เงื่อนไข เจาะถึงอาคารรายหลัง 177,647 หลัง |
| กิจการพลังงาน | ทะเบียนน้ำมันเชื้อเพลิง 203 ราย อาคารและโรงงานควบคุม 18 แห่ง โครงการพลังงานทดแทน 69 รายการพร้อมภาพ 64 ภาพ แยกตามตำบล รวมระบบสูบน้ำพลังงานแสงอาทิตย์ 58 รายการ 103 ระบบ 360 กิโลวัตต์ |
| โอกาส | เลือกมุมมองได้สูงสุด 3 จาก 7 มุมมองที่อ้างแผนและอำนาจหน้าที่ ได้คิวตำบลชวนสำรวจเฉพาะตำบลที่ผ่านเกณฑ์ Demand พร้อมเหตุผล งานแรก และสิ่งที่ต้องตรวจ เกณฑ์ตัวเลขเป็นค่าตัวอย่างที่ปรับได้ |
| เล็งไว้ | เก็บพื้นที่ที่เลือกพร้อมรอบข้อมูลและรุ่นเกณฑ์ ใส่ผู้รับผิดชอบและงานถัดไป ดาวน์โหลด CSV |
| ขอข้อมูล | ช่องข้อมูลที่ควรขอจาก กฟภ. ผู้จำหน่ายน้ำมันและ LPG และกรมการขนส่งทางบก พร้อมระดับการเปิดเผย |
| ที่มา | แหล่ง วิธีคิด ป้ายชนิดค่า และภาพโครงการจากไฟล์ต้นทาง |

ทุกมุมมองมี permalink ใน URL เช่น `?v=demand&lvl=lao&a=04180102&b=04180102-00001` เปิดอาคารรายหลัง ปุ่มย้อนกลับของเบราว์เซอร์คืนมุมมองก่อนหน้า

ขอบเขตการเผยแพร่: แสดงทุกช่องจากไฟล์ทะเบียน รวมชื่อผู้ประกอบการและบ้านเลขที่ ยกเว้นเบอร์โทรศัพท์ส่วนบุคคลของผู้ติดต่อโครงการ ไฟล์ต้นทางไม่มีพิกัดรายแห่ง แผนที่จึงแสดงจำนวนต่อตำบลโดยไม่วางหมุดคาดเดา ไม่เผยแพร่ไฟล์ต้นฉบับ

## สีและดีไซน์

- Landometer Design System 0.9.7 (`v0.9.7-owner.1`, `color-srgb-10`) มีธีมอัตโนมัติ สว่าง และมืด จำค่าที่เลือกไว้ในเบราว์เซอร์
- ทุก choropleth ใช้สเกล 41 ระดับตามอันดับเปอร์เซ็นไทล์ สีข้อมูลเป็น HEX เดียวกันทั้งสองธีม ค่าศูนย์ที่นับแล้วมีเส้นขอบแยก ค่าที่ไม่มีข้อมูลไม่ระบายสี
- ทุกตัวเลขบอกชุดข้อมูล แหล่ง วันที่ และขอบเขต ทุกแผนที่มีรายการพื้นที่แบบไม่ใช่แผนที่ในแผงรายละเอียด

## เปิดบนเครื่องและตรวจ

```sh
python3 -m http.server 4173 --bind 127.0.0.1
node scripts/qa.mjs
```

`scripts/qa.mjs` ต้องมี Playwright (ตั้ง `PLAYWRIGHT_MODULE` เป็น path ของ `playwright/index.mjs` ได้) ตรวจไฟล์ ข้อมูล ความเป็นส่วนตัว สีตาม LUT41 ธีม ขนาดปุ่ม และทุกมุมมองที่ 1440 768 และ 390 พิกเซล ใช้ `BASE_URL=https://montri-th.github.io/chainat-energy/` เพื่อตรวจหน้าเว็บจริง ผลล่าสุดอยู่ใน [docs/QA.md](docs/QA.md)
