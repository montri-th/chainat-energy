# CityMETER: Yolk · โหมดสำนักงานพลังงานจังหวัด (ชัยนาท)

เดโมการใช้ CityMETER: Yolk กับภารกิจของสำนักงานพลังงานจังหวัดชัยนาท ใช้ลำดับคิดและกติกาเดียวกับโหมดขยายสาขาของธุรกิจ คือ ความต้องการ → กิจการที่มีอยู่ → โอกาส → คิวลงพื้นที่ ต่างกันที่ตัววัด เกณฑ์ และมุมมองโอกาส ซึ่งโหมดนี้ผูกกับแผนปฏิบัติราชการด้านพลังงาน จ.ชัยนาท 2566–2570 และอำนาจหน้าที่ของสำนักงาน ลำดับคิดเขียนเป็น JavaScript ในหน้าเว็บ ไม่ได้เรียกเครื่องคิดของ production

**เปิดเดโม:** https://montri-th.github.io/chainat-energy/

เป็นต้นแบบสาธิต ไม่ใช่ระบบราชการที่เปิดใช้งานจริง ตัวเลขความต้องการรายพื้นที่และรายอาคารเป็นแบบจำลองจากยอดจังหวัดจริง

## สีและดีไซน์

ผังแผนที่ล่าสุด: รวมเครื่องมือเป็นแถบเดียว คืนพื้นที่เหนือ canvas ย้ายเครดิตไว้ใต้แผนที่ และให้จอเล็กกว่า 1100 px อ่านรายละเอียดต่อใต้แผนที่ ดู [layout contract](docs/map-layout.json)

19 ต.ค. 2569: hero ใช้ animated Landometer Logo **quiet** เล่นหนึ่งครั้ง 3.36 วินาทีแล้วค้างภาพนิ่ง ไม่มีปุ่มหยุดตามคำขอเจ้าของงาน ใช้ภาพนิ่งต้นฉบับเมื่อปิดการเคลื่อนไหวหรือไฟล์ไม่พร้อม ดู [สัญญา motion และแหล่งไฟล์](docs/quiet-logo-motion.json) ผล UI v2 และชุด Drive v2 เป็น snapshot ก่อนการแก้ hero รอบนี้

- Landometer Design System 0.9.7 (`v0.9.7-owner.1`, `color-srgb-10`) มีธีมอัตโนมัติ สว่าง และมืด จำค่าที่เลือกไว้ในเบราว์เซอร์
- ทุก choropleth ใช้สเกล 41 ระดับตามอันดับเปอร์เซ็นไทล์ สีข้อมูลเป็น HEX เดียวกันทั้งสองธีม ค่าศูนย์ที่นับแล้วมีเส้นขอบแยก ค่าที่ไม่มีข้อมูลไม่ระบายสี
- ชนิดเชื้อเพลิงในกราฟรถใช้สีหมวด `landometer-series-10-v8` แบบ soft fill ตาม DATAVIZ-05 ใช้ค่าของธีมสว่างและธีมมืดตามที่ LDS กำหนด คู่กับรูปทรงกำกับ (วงกลม สี่เหลี่ยม สามเหลี่ยม ข้าวหลามตัด กากบาท) และมีตารางแทนกราฟ
- ทุกตัวเลขบอกชุดข้อมูล แหล่ง วันที่ และขอบเขต ทุกแผนที่มีรายการพื้นที่แบบไม่ใช่แผนที่ในแผงรายละเอียด

## แผนที่พื้นหลังและตัวตนเว็บ · UI v2, 19 ต.ค. 2569

คงโครงหน้า แหล่งข้อมูล สูตร เกณฑ์ 17 ตัววัด และ 7 มุมมองเดิมของ Claude เพิ่มโลโก้และไอคอนที่ตรวจเทียบต้นแบบ Yolk, เมนูรวม, favicon และภาพแชร์สำหรับชัยนาท โดยภาพแชร์ไม่มีใบหน้าหรือพิกัดที่ยังไม่ได้รับอนุญาต ดูขอบเขตและ hash ใน [identity manifest](docs/identity-manifest.json)

เลือกพื้นวิเคราะห์เดิม ถนนแบบเรียบ ถนนละเอียด หรือดาวเทียม Sentinel-2 ปี 2021 ความละเอียด 10 เมตรได้ การปิดสีพื้นที่เป็นการแสดงผลเท่านั้น ไม่เปลี่ยนคะแนน เกณฑ์ หรือคิว ข้อมูลอาคารและค่าที่แสดงยังเป็นชุดเดิม ภาพและถนนไม่ยืนยันพิกัดสถานที่หรือสถานะภาคสนาม

- ถนน: [OpenStreetMap contributors](https://www.openstreetmap.org/copyright) ใช้ tile ปกติตาม [นโยบาย OSM](https://operations.osmfoundation.org/policies/tiles/) ไม่ดาวน์โหลดล่วงหน้าหรือเก็บเพื่อใช้ offline
- ดาวเทียม: © ESA WorldCover project 2021 / Contains modified Copernicus Sentinel data (2021) processed by ESA WorldCover consortium ผ่าน [Terrascope WMTS](https://docs.terrascope.be/Developers/WebServices/OGC/WMTSv2.html) และ [ESA data access](https://esa-worldcover.org/en/data-access) ภายใต้ CC BY 4.0 มีพื้นถนนรองรับส่วนภาพโปร่งใส
- ค่าเริ่มต้นไม่เรียกผู้ให้บริการภายนอก เมื่อเลือกพื้นหลังภายนอก เบราว์เซอร์จะขอภาพตามมุมมองปัจจุบันโดยตรง บริการภายนอกอาจไม่พร้อมใช้งาน ระบบกลับไปพื้นวิเคราะห์พร้อมปุ่มลองใหม่และคงพื้นที่/กล้องเดิม

วันที่ปรับหน้าตาไม่ใช่วันที่อัปเดตข้อมูล: คง data release `cnt-energy-2026-10-18-r2` ไม่รับพิกัด Fuel Now เข้าทะเบียนในรอบนี้ ผู้ใช้ production วางไว้ 5 คน (Admin 1 / Editor 2 / Viewer 2) โดยสิทธิ์ตาม Yolk เดิม ระบบ static ปัจจุบันยังไม่ได้บังคับสิทธิ์เหล่านี้
