# CityMETER · Chainat Energy demo

เดโมแพลตฟอร์มข้อมูลพลังงานจังหวัดชัยนาท สำหรับทดลองแนวทางรวมข้อมูลพลังงานเชิงพื้นที่ระดับจังหวัด

**เปิดเดโม:** https://montri-th.github.io/chainat-energy/

## ทดลองใช้งาน

1. เลือกกลุ่มข้อมูลและอำเภอจากแผนที่ขอบเขตจริงของ 8 อำเภอ
2. เปิดตารางรายอำเภอ ค้นหา กรอง ดูที่มา และดาวน์โหลดข้อมูลสรุป CSV
3. ดูที่มา ความพร้อมของ 6 กลุ่มข้อมูลที่วางไว้ และข้อจำกัดของข้อมูล
4. เปิดพื้นที่ทดลองเจ้าหน้าที่ เพิ่มรายการสมมติ หรือนำเข้า CSV ตัวอย่างแบบตรวจสอบก่อนเพิ่ม เลือกบทบาทผู้บันทึก/ผู้ตรวจทานเพื่อทดลองร่าง → ตรวจทาน → เผยแพร่จำลอง รวมการคืนแก้ไข การสร้างเวอร์ชันใหม่ และการเก็บเข้าคลัง

การแก้ไขในพื้นที่ทดลองบันทึกใน localStorage ของเบราว์เซอร์เท่านั้น รายการจำลองไม่เพิ่มเข้าแผนที่และตัวเลขจากต้นทาง การสลับบทบาทใช้สาธิตขั้นตอน ไม่ใช่การเข้าสู่ระบบหรือการบังคับสิทธิ์จริง

## ข้อมูลที่แสดง

แก้ไข 17 ต.ค. 2569: ยอดโครงการเปลี่ยนจาก 57 เป็น 69 รายการ หลังพบ 12 แถวในใบงาน 01 Solar pumping ที่ช่องลำดับว่างแต่มีข้อมูลโครงการครบ

| กลุ่ม | จำนวน | หน่วยนับ |
| --- | ---: | --- |
| ผู้ประกอบการเชื้อเพลิง | 203 | แถวทะเบียนในไฟล์ |
| อาคารและโรงงานควบคุม | 18 | แถวทะเบียนในไฟล์ |
| โครงการส่งเสริมพลังงาน | 69 | รายการสนับสนุนหลังตัด 15 แถวมุมมองซ้ำ |

ยอดรวม 290 รายการมีหน่วยนับต่างกัน ไม่ใช่จำนวนสถานประกอบการที่ยืนยันแล้ว โครงการอยู่ในช่วง พ.ศ. 2558–2568 ไฟล์ต้นทางไม่ระบุวันที่ปรับปรุงและไม่มีช่องพิกัดรายแห่ง จึงไม่แสดงหมุดคาดเดาหรือคำนวณ coverage เป็น 0%

เผยแพร่เฉพาะข้อมูลรวมระดับอำเภอ/ประเภท ไม่รวมไฟล์ต้นฉบับ ชื่อรายบุคคล/ผู้ประกอบการ เบอร์โทรศัพท์ เลขใบอนุญาต ลายเซ็น หรือที่อยู่ละเอียด ดูวิธีนับและการกระทบยอดใน [บันทึกคุณภาพข้อมูล](data/DATA_QA.md)

EV และโครงสร้างพื้นฐานอื่นไม่มีต้นทางในชุดที่ได้รับ ทะเบียน Solar แยกยังไม่มี ส่วนรายการในใบงาน Solar pumping 59 รายการเป็นส่วนหนึ่งของ 69 รายการโครงการ จึงไม่นับเป็นอีกชุดข้อมูล

## แผนที่และอัตลักษณ์

ขอบเขตอำเภอปี 2019 จาก Royal Thai Survey Department / OCHA ROAP ผ่าน geoBoundaries gbOpen ภายใต้ CC BY 3.0 IGO ใช้เพื่อภาพรวม ไม่ใช่หลักฐานแนวเขตตามกฎหมาย ดู [รายละเอียดสิทธิ์และที่มา](data/DISTRICT_BOUNDARIES.md)

ใช้ LDS 0.9.7, release `v0.9.7-owner.1` พร้อมฟอนต์และโลโก้ทางการที่มีอยู่ในชุดปัจจุบัน สเกลจำนวนใช้ค่าต้นฉบับ 5 classes ไม่เปลี่ยนสีตาม theme ผลตรวจ package ไม่ใช่คำรับรองว่าผ่านกฎทุกข้อของ artifact ดูขอบเขตที่ใช้และข้อจำกัดใน [build record](docs/build-record.json)

## เปิดบนเครื่อง

เว็บเป็น HTML/CSS/JavaScript แบบ static ไม่ต้องติดตั้ง dependency เพื่อใช้งาน

```sh
python3 -m http.server 4173 --bind 127.0.0.1
```

เปิด `http://127.0.0.1:4173` ต้องเปิดผ่าน HTTP เนื่องจาก browser อ่าน JSON ด้วย fetch

## เผยแพร่และพัฒนาต่อ

GitHub Pages ใช้สาขา `main` โฟลเดอร์ `/` และ `.nojekyll` ข้อมูลเดโมอยู่ใน `data/energy-data.json` หน้าเว็บไม่มี API ที่เขียนข้อมูลบน server และไม่เชื่อม production ของ CityMETER

ก่อนใช้ปฏิบัติงานจริง ต้องมีฐาน master ที่ยืนยันแล้ว สิทธิ์การเผยแพร่ราย field ระบบยืนยันตัวตน/สิทธิ์ ฐานข้อมูลกลาง versioning และ audit ฝั่ง server รวมทั้งทดสอบ backup/restore ตามแผน ซึ่งเป็นงานนอกขอบเขตเดโมนี้

ผลการตรวจที่ทำจริงบันทึกใน [QA](docs/QA.md)
